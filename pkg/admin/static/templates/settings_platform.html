Production DNS Setup Guide

Steps for migrating to production DNS with Route53

1

Create Route53 Hosted Zone

Create a hosted zone for your domain (e.g., apps.example.com) in AWS Route53 or your DNS provider.

2

Configure DNS Delegation

Set NS records in your parent domain pointing to the hosted zone's nameservers. Add A/CNAME records pointing *.apps.example.com to your cluster's Ingress Controller load balancer.

3

Install cert-manager with Let's Encrypt

Deploy cert-manager to your cluster and configure a ClusterIssuer with ACME (Let's Encrypt) for automatic TLS certificate provisioning.

4

Update mf.yaml

Change the cluster domain, admin domain, and auth issuer URL to your production domain. Remove hosts file entries once DNS is configured.
